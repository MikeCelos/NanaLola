Database & Cloud Setup (Permanent Accounts)

Render's free tier uses temporary containers that reset when updated or after 15 minutes of inactivity. Connecting a 100% Free PostgreSQL Cloud Database keeps all user accounts, novels, and writing sessions permanently safe!

Step 1: Get Your Free Database (1 min)
  • Go to Neon.tech (Recommended: free forever, never expires) or Supabase.com.
  • Sign up for free and create a new project.
  • Copy the Connection String (format: postgresql://...).
Step 2: Add to Render Dashboard
  • Open dashboard.render.com.
  • Select your NanaLola web service.
  • Go to the Environment tab.
  • Add an environment variable:
  • Key: DATABASE_URL
  • Value: (Paste the connection string you copied)
  • Click Save Changes.

Render will automatically restart, and all your accounts and books will be permanently stored in the cloud!
